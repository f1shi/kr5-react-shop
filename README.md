## Структура React-компонентов

- `CatalogPage` — хранит состояние каталога.
- `CatalogControls` — отображает поле поиска, фильтр и сортировку.
- `ProductList` — отображает список товаров.
- `ProductCard` — отображает карточку одного товара.

## Примечание

Полноценная корзина, сохранение в `localStorage`, избранное и расширенная форма будут относиться к следующим этапам или самостоятельным доработкам.

## Связь с предыдущими контрольными работами

Проект является SPA-версией интернет-магазина, который ранее разрабатывался в HTML/CSS и JavaScript. Товары перенесены из массива `products` проекта `kr4-js-shop`.

На следующих этапах будут добавлены состояние, поиск, фильтрация, сортировка, формы, маршрутизация и API-слой.
