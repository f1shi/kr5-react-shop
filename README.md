## Примечание по useEffect

`useEffect` используется для синхронизации состояния React с внешней системой — `localStorage`. Для обычных вычислений, например расчёта ошибок формы из `formData`, используется отдельная функция, а не эффект.

Сохранение черновика начинается только после того, как черновик прочитан из `localStorage` (флаг `isDraftLoaded`). Без этого флага в режиме `StrictMode` эффект сохранения успевал бы записать пустую форму поверх сохранённого черновика. Пустая форма не сохраняется: ключ удаляется.
